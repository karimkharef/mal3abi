# mal3abi
ملعبي — تطبيق حجز ملاعب كرة القدم
تطبيق ويب عربي (من اليمين إلى اليسار) لحجز ملاعب الحي بسهولة. يعمل على الحاسوب والهاتف، ويمكن تثبيته على أندرويد كتطبيق، ويُخزّن الحجوزات ويعمل حتى دون اتصال بالإنترنت.

📋 نظرة عامة
العنصر	الوصف
الاسم	ملعبي
الوظيفة	حجز ملاعب كرة القدم في الحي
اللغة	العربية (RTL)
النوع	تطبيق ويب + PWA (قابل للتثبيت)
التخزين	قاعدة بيانات المنصة أو تخزين محلي دائم
✨ المميزات
حجز على ثلاث خطوات بسيطة مع شريط تقدّم يوضح مكانك.
تشكيلة الفريقين على شكل ملعب كرة حقيقي: حارس، ظهير أيمن/أيسر، قلب دفاع، وسط، صانع ألعاب، مهاجمون… لكل فريق.
قسم المباريات المباشرة: يعرض المباريات الجارية الآن ووقت انتهائها والوقت المتبقي، مع مباريات اليوم وحالتها (مباشر / قادمة / انتهت).
لوحة إدارة محمية باسم مستخدم وكلمة سر.
ترتيب الطلبات حسب وقت الحجز: الأسبق حجزاً يظهر أولاً برقم #1.
التحقق من الحقول: لا يمكن المتابعة أو تأكيد الحجز دون إكمال البيانات المطلوبة.
حركات انتقالية بين الخطوات، وتأثيرات لمس، وأشرطة تقدم متحركة.
الوضع الليلي تلقائياً حسب إعدادات الجهاز.
يعمل كتطبيق على الهاتف (PWA) بأيقونة على الشاشة ووضع ملء الشاشة، مع دعم العمل دون اتصال.
🚀 طريقة الاستخدام (الحجز)
الخطوة ١ — بياناتك
أدخل الاسم الكامل.
أدخل رقم بطاقة التعريف الوطنية (18 رقماً بالضبط).
لا يُفعّل زر التالي حتى تكتمل البيانات بشكل صحيح.
الخطوة ٢ — الوقت والملعب
اختر نوع الحجز: حجز عادي أو بطولة.
اختر التاريخ والساعة.
اختر الملعب من بطاقات الملاعب (يظهر المتاح/المحجوز).
في حالة البطولة: اختر عدد الأسابيع ويظهر السعر الإجمالي.
لا يُفعّل التالي حتى تختار ملعباً.
الخطوة ٣ — الفريقان والتشكيلة
أدخل اسم الفريق الأول واسم الفريق الثاني.
اضغط على أي مركز في الملعب لإضافة اسم اللاعب (اختياري).
يمكنك التبديل بين الفريقين لإكمال تشكيلة كل منهما.
لا يُفعّل زر تأكيد الحجز حتى تدخل اسمي الفريقين.
بعد التأكيد
ينتقل الحجز إلى صفحة حجوزاتي بحالة «في الانتظار».
يبقى كذلك حتى يقوم المسؤول بـالقبول أو الرفض.
يمكنك إلغاء حجز لا يزال في الانتظار.
🔴 قسم المباريات المباشرة (مباشر)
يعرض تبويب مباشر:

مباشر الآن: كل مباراة جارية حالياً مع:
اسم الملعب.
الفريقان (الفريق الأول ضد الفريق الثاني).
وقت البداية والنهاية.
الوقت المتبقي بالدقائق.
شريط تقدّم متحرك.
مباريات اليوم: جميع مباريات اليوم مؤكدة، مرتبة حسب الساعة، مع حالة كل واحدة: مباشر / قادمة / انتهت.
تظهر المباراة في قسم المباشر فقط إذا كان حجزها مؤكداً وكانت ساعة المباراة هي الساعة الحالية.
